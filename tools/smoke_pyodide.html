kaypy in Pyodide

Eight checks, in order, each gating the next: can a browser load pygame-ce, install kaypy from PyPI, hand SDL a canvas, and then actually run a game loop at a sensible frame rate. This is the question PyIDE's engine swap rests on, so it gets answered by running it rather than by reasoning about it.

Running…

Pyodide is about 10 MB. The first load takes a few seconds.

    Click the picture, then use the arrow keys and space.

    What is being run. A real kaypy game — gravity, a static floor, a player with body() and area(), arrow keys and a jump. No image files, so nothing here depends on how PyIDE will serve its sprite packs; that is a separate question.

    Versions. Pyodide 314.0.7 carries pygame-ce 2.5.7 — the same pygame-ce that pygbag supplies to kaypy's own web export, so the browser build is one kaypy already targets.
